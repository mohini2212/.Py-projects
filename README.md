🧩 Projects
Basic Level

1. Calculator A simple command-line calculator supporting standard arithmetic operations, built to practice core Python fundamentals like functions and control flow.

2. Number Guessing Game A CLI game where the user tries to guess a randomly generated number within a limited number of attempts, with feedback (higher/lower) after each guess.

Intermediate Level

3. To-Do List Application A command-line to-do list app that stores tasks in CSV format, supporting adding, viewing, updating, and deleting tasks.

4. Web Scraper A web scraping script targeting books.toscrape.com, extracting book details (title, price, rating, availability) and saving them for further use.

Advanced Level

5. File Encryption/Decryption A tool using the cryptography library's Fernet symmetric encryption to securely encrypt and decrypt files via a key-based system.

6. N-Queens Solver A backtracking algorithm implementation that solves the classic N-Queens problem, printing all valid board configurations for a given N.

🛠️ Tech Stack
Language: Python 3
Key Libraries: cryptography (Fernet), requests / BeautifulSoup (web scraping), csv, random
